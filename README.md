# UIU Installment & Tuition Calculator

Official link: **[https://mashurul138.github.io/Installment_Calculator/](https://mashurul138.github.io/Installment_Calculator/)**

A modern, fast, and offline-capable tuition fee & installment calculator tailored specifically for **United International University (UIU)** students (Trimester and Pharmacy Semester programs).

## Features
- **Official Milestones:** Automatic calculation of installment dates and amounts (40% / 30% / 30% for Trimester; 4 equal installments for B.Pharm).
- **Scholarship & Waivers:** Accurate waiver deduction with course exemptions (FYDP, Capstone Project, etc.).
- **Payment Reconciliation:** Input actual amount paid at registration or installments to see live redistributed balances.
- **Course Drop & Refund Policy:** 100% and 50% refund windows computed directly according to UIU Academic Calendar deadlines.
- **Offline & Instant Load (PWA):** Powered by modern Service Worker caching and asynchronous asset loading for 0 wait time even on slow or intermittent internet connections.
- **Share & Print:** One-click copy for WhatsApp/Messenger, shareable URL query parameters, and printable fee voucher generation.
